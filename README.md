# Анализ успеваемости

Лабораторная работа № 2 по дисциплине «Проектирование веб-сайтов».

Программа рассчитывает средний балл, находит лучшего студента, выводит имена студентов с баллом ниже 60 и присваивает буквенные оценки. Оценка A начинается с 90 баллов, B — с 75, C соответствует баллу ниже 75.

Запуск из корня репозитория в Node.js 22:

```sh
node main.js
```

Рабочая ветка — `develop`. Изменения из личной ветки поступают в неё через pull request. Готовая версия переносится из `develop` в `main`.
